# 地图资源格式文档

## 1. 文件分层

### 1.1 `.map` 文件 — 地图元数据
- **位置**: `data/map/{id}.map`
- **用途**: 包含地图名称、选项配置、缩略图、作者信息等展示层数据
- **解析**: 由 `map_parser.py` 中的 `MapOptionParser` 解析

### 1.2 `.sl` 文件 — 运行态地图包（压缩）
- **位置**: `data/map/{id}.sl`
- **格式**: LZMA 压缩流
- **头部结构**（13 字节）:
  - 字节 0~4: LZMA 属性（固定为 `5d 00 00 40 00`，对应 pb=5, lp=0, lc=3, dict_size=64MB）
  - 字节 5~12: 解压后大小（uint64 little-endian）
- **解压**: 使用 Python `lzma` 模块，`FORMAT_RAW`，`FILTER_LZMA1`，dict_size=67108864
- **解压后**: `LuaRDGTM` 格式的运行态地图包

### 1.3 解压后地图包 — LuaRDGTM 格式
- **头部**: 前 8 字节为 ASCII 字符串 `LuaRDGTM`
- **后续结构**: 待进一步分析（段数量、偏移表、内嵌脚本名等）
- **用途**: 这是游戏引擎实际加载的地图运行时数据

## 3. 挂载点

### 3.1 候选路径
- `data/sl/map.map`
- `data/core/sl/map.map`

### 3.2 当前策略
原始启动器生成的 `10002_dec.bin` 同时复制到上述两个路径。当前启动器沿用此做法，待实验确认最小必要路径。

## 4. 边界与限制

- `.sl` 文件缺失时该地图不可启动
- `.map` 文件缺失时该地图在 UI 中不可见或无法解析选项
- 解包失败时必须在 UI 层明确提示，不静默跳过
